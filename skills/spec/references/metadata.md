# Compact spec metadata

Use only applicable fields: `id`, `title`, `summary`, `status`, `scope`, `risk`, `risk_domains`, `reversibility`, `change_surfaces`, `contracts`, `review_policy`, `test_provenance`, `navigation`, `authority`, `dependencies`, and `origin`.

Metadata supports routing and triage. It is not an implementation input by itself. Use stable scalar or short-list values, repository-relative paths, and explicit authority lists. Do not embed secrets, prompts, or full evidence logs.
