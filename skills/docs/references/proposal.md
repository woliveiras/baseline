# Proposal

For an unresolved material design, use the repository's RFC or proposal convention. Otherwise copy the bundled [RFC asset](../assets/rfc-template.md). Record problem evidence, goals, non-goals, proposed behavior and interfaces, alternatives, security, reliability, operability, compatibility, migration, rollback, validation, and open decisions.

Keep status clearly proposed and identify the decision owner. A discussion may improve the proposal but cannot silently grant implementation or release authority. When accepted, retain the RFC as history and summarize only the durable decision in an ADR when the ADR threshold is met.

The lightweight public proposal and review model is informed by npm RFCs: https://github.com/npm/rfcs.
